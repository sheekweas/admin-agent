## 4. Наблюдаемость и аварийное отключение AI

- `/metrics` (Prometheus): RED-метрики по шаблону маршрута, outbox, задачи, уведомления/DLQ, ошибки AI, звонки
  эскалации, `crm_db_up`, `crm_ai_globally_disabled`. Тесты `tests/test_ops_v1.py`: доступ (внутренняя сеть / токен /
  отключение), отсутствие сырых путей и id в метках, значения gauge после сбоя AI, работа при недоступной БД.
- Kill switch `AI_GLOBALLY_DISABLED=true`: тесты подтверждают — модель не вызывается, клиенту уходит резервное
  сообщение, создаётся задача (high), диалог переходит к человеку, повторных сообщений/задач нет; звонок сразу
  переводится администратору; песочница знаний — 503. Уровень организации (`settings.ai.enabled`) уже был
  (`test_ai_disabled_stays_silent`). Процедура — [OPERATIONS.md §7](OPERATIONS.md#ai-провайдер-недоступен).

## 6. Открытые ограничения

| # | Ограничение | Что нужно для закрытия |
|---|---|---|
| 1 | **WhatsApp live** не проверялся с реальным номером Meta (подписи, форматы и 24-часовое окно покрыты тестами по документации) | WABA, номер, system-user токен, одобренный шаблон; пройти go-live чек-лист [ONBOARDING_BUSINESS.md §7](ONBOARDING_BUSINESS.md) |
| 2 | **Telegram live** не проверялся с реальным ботом | токен бота, `/start` администраторов, «Проверить» |
| 3 | **Twilio в реальной сети (AT-18, AT-05)**: слышимость, перебивание, DTMF, перевод на человека | аккаунт Twilio не trial, номер, доступность KZ-номеров/направлений; процедура AT-18 |
| 4 | **Казахский TTS**: у Twilio нет казахского голоса, по умолчанию казахский текст читает русский голос — понятно, но с акцентом | оценить на AT-18; при появлении голоса — сменить `tts_voice_kk`/`tts_language_kk` |
| 5 | **STT для голосовых сообщений WhatsApp**: только интерфейс + mock; `STT_PROVIDER=none` → голосовые идут человеку | выбрать провайдера, проверить качество KK на реальных записях (ТЗ §24), реализовать адаптер `app.ai.stt.SpeechToText` |
| 6 | **WhatsApp Business Calling** — заглушка за флагом `WHATSAPP_CALLING_ENABLED` | одобрение Meta для аккаунта/страны, BSP с медиашлюзом |
| 7 | Голосовой диалог пошаговый (Gather/Say): задержка ответа 1–3 с, не потоковый | при необходимости — потоковый медиаканал (отдельный этап) |
| 8 | Выгрузка бэкапов в S3 не проверена с реальным бакетом; RPO 24 ч без WAL-архивации | бакет + ключ; при требовании RPO < 24 ч — pgBackRest/WAL-G |
| 9 | JWT без отзыва (12 ч), ограничение частоты по IP без WAF | [SECURITY.md §5](SECURITY.md#5-known-limitations--follow-ups) |
| 10 | Нагрузка измерена на одном хосте, 1 процесс API, mock-LLM; панель p95 0,76 с при текущем объёме демо-данных (в v0.3 — 0,39 с при меньшем объёме и без параллельной сборки на хосте) | повторить `scripts/load/` на целевом сервере с ожидаемой нагрузкой пилота |
| 11 | Метрики платформенные (без разбивки по арендаторам в Prometheus) | по арендаторам — отчёты панели/SQL; при необходимости добавить метки tenant |

## 7. Решения, которые остаются за заказчиком (ТЗ §25)

- [ ] **Каналы**: один WhatsApp-номер на филиал или на организацию; кто владеет WABA и номерами (платформа или бизнес).
- [ ] **Телефония**: только Twilio/обычная связь или также WhatsApp Calling; провайдер и номера для Казахстана.
- [ ] **Запись**: нужна ли предоплата; кто подтверждает бронь (`requires_admin_confirmation`); время удержания слота (`hold_ttl_min`, по умолчанию 3 мин).
- [ ] **График**: кто может менять смены; можно ли переносить клиента без отдельного согласия.
- [ ] **Админ**: кому звонить при SLA 10 мин, что делать ночью (тихие часы по умолчанию 22–8), число попыток (по умолчанию 2) и резервный администратор.
- [ ] **CRM**: обязательные статусы лидов и сегменты (в системе — стандартный набор стадий и тегов).
- [ ] **Финансы**: кассовая интеграция или ручное подтверждение (реализовано ручное); учёт скидок и возвратов.
- [ ] **AI**: модель и языки (по умолчанию `claude-opus-5-5`, RU/KK); можно ли записывать и хранить разговоры (запись выкл., срок хранения расшифровок 90 дней); запреты по нишам.
- [ ] **SaaS**: тарификация (филиалы / мастера / сообщения / минуты / фикс) и кто оплачивает сообщения, минуты и токены ([THIRD_PARTY.md §4](THIRD_PARTY.md)).
- [ ] **Право и данные**: где хостить БД и бэкапы, кто оператор данных, сроки хранения переписок и аудио; юридический чек-лист [THIRD_PARTY.md §5](THIRD_PARTY.md).
- [ ] **Запуск**: пилотный бизнес, число мастеров, заявок в день, ожидаемая нагрузка; требования к RPO/RTO (сейчас 24 ч / 4 ч).
- [ ] Контакты поддержки и дежурства — [OPERATIONS.md §9](OPERATIONS.md#9-поддержка-и-контакты).
