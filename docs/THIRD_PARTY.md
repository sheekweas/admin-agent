# Сторонние сервисы, тарифы и ответственность (ТЗ §23.1, §24, §27)

Цены в этом документе намеренно **не указаны**: тарифы провайдеров меняются, зависят от страны, объёма и
договора. Для каждой строки: «по тарифу провайдера, проверить на дату запуска» по официальной ссылке.
Колонка «Кто платит» — предложение по умолчанию; окончательное решение — за заказчиком (см. §4).

## 3. Контроль расходов (ТЗ §24 «Непредсказуемые API-расходы»)

- LLM: лимит расходов в Anthropic Console; токены каждого хода сохраняются в `ai_runs.input_tokens/output_tokens`
  (основа для дашборда расходов по арендаторам); аварийное отключение — `AI_GLOBALLY_DISABLED=true` или
  `settings.ai.enabled=false` для одного арендатора.
- WhatsApp: шаблоны вне 24-часового окна платные — отправляются только напоминания/подтверждения, рассылки
  уважают opt-out (AT-13).
- Twilio: лимит исходящих AI-звонков `settings.voice.max_outbound_per_day`, окно `outbound_hours`,
  `escalation.max_call_attempts`, тихие часы; запись разговоров по умолчанию выключена.

## 4. Решения, которые принимает заказчик

- [ ] Чей аккаунт Meta Business / WABA: платформы (один BSP-аккаунт) или каждого бизнеса? Один номер на филиал или на организацию? (ТЗ §25)
- [ ] Кто оплачивает сообщения WhatsApp, минуты Twilio и токены LLM: включено в подписку или перевыставляется арендатору?
- [ ] Провайдер телефонии для Казахстана: Twilio (наличие KZ-номеров и регуляторные требования — проверить) или местный SIP-оператор (потребуется адаптер)?
- [ ] STT-провайдер для голосовых сообщений (качество казахского — проверить на реальных записях, ТЗ §24).
- [ ] Хостинг: страна/провайдер с учётом требований к локализации персональных данных (§5).
- [ ] Тарификация SaaS (ТЗ §25): по филиалам, мастерам, сообщениям, минутам или фиксированная.

## 5. Юридические и провайдерские проверки перед запуском (ТЗ §20.2, §24) — чек-лист

> Это перечень вопросов для юриста, а не юридическое заключение.

- [ ] Применимость законодательства РК о персональных данных и их защите; кто оператор данных (платформа или каждый бизнес), кто обработчик; договор поручения обработки.
- [ ] Требования к месту хранения (локализации) персональных данных граждан РК и к трансграничной передаче: БД, бэкапы (S3-регион), обработка текстов моделью LLM за рубежом, Meta, Twilio, Telegram.
- [ ] Согласия клиентов: обработка ПДн, маркетинговые рассылки, исходящие звонки, запись разговоров (в системе — `consent_flags`, opt-out, предупреждение о записи); тексты согласий и политика конфиденциальности на сайте/в профиле WhatsApp.
- [ ] Стоматологии: правила обработки медицинской информации (в системе — `niche.medical_safe_mode`, AI даёт только организационные ответы).
- [ ] Запись телефонных разговоров и раскрытие, что говорит AI (приветствие раскрывает AI; запись выключена по умолчанию).
- [ ] Сроки хранения переписок, расшифровок и аудио; процедура удаления/экспорта по запросу субъекта (экспорт контактов CSV есть; удаление — через поддержку, см. OPERATIONS.md).
- [ ] Условия Meta: WhatsApp Business Messaging Policy и Commerce Policy (запрещённые категории, opt-in, шаблоны) — https://business.whatsapp.com/policy
- [ ] Условия Twilio (Acceptable Use Policy, регуляторные требования к номеру страны), Telegram Bot terms, Anthropic Usage Policy.
- [ ] Журнал инцидентов и порядок уведомления об утечке ПДн (сроки по законодательству — уточнить у юриста).
