### Совместимость

### Безопасность — серверные сессии и отзыв JWT (v1.1.0, часть A)
- Таблица `auth_sessions` (миграция `0003_auth_sessions`): вход создаёт сессию, JWT получает claim `sid`; токен с отозванной,
  истёкшей или неизвестной сессией получает 401 на любом запросе. **Токены v1.0 (без `sid`) больше не принимаются —
  после обновления все пользователи входят заново один раз.** `last_seen_at` обновляется не чаще раза в 5 минут.
- Новые эндпоинты: `POST /v1/auth/logout`, `POST /v1/auth/logout-all`, `GET /v1/auth/sessions`,
  `DELETE /v1/auth/sessions/{id}`, `POST /v1/auth/change-password` (мин. 10 символов, не только цифры; остальные сессии
  завершаются), `POST /v1/team/{membership_id}/sign-out` (право `team.manage`: владелец/администратор).
- Отключение пользователя завершает все его сессии, отключение участника — его сессии в этой организации.
- Аудит: `auth.logout`, `auth.logout_all`, `auth.session_revoked`, `auth.password_changed`, `auth.user_signed_out`.
- Задача воркера `ops.purge_auth_sessions` (раз в час) удаляет сессии, истёкшие или отозванные более 30 дней назад.

### Добавлено — распознавание голосовых и приватность звонков (v1.1.0, часть B)
- **STT для голосовых сообщений WhatsApp**: адаптер `OpenAICompatibleSTT` (`POST {STT_BASE_URL}/audio/transcriptions`,
  `verbose_json`, подсказка языка ru/kk) — OpenAI Whisper, Groq, self-hosted faster-whisper. Переменные `STT_PROVIDER`
  (`openai_compatible|mock|none`), `STT_BASE_URL`, `STT_API_KEY`, `STT_MODEL` (`whisper-1`), `STT_TIMEOUT_SEC` (30);
  максимум 25 МБ. Уверенность — среднее `exp(avg_logprob)` по сегментам. Таймаут / 5xx / ошибка → `STTError` →
  передача человеку. Ключ не логируется и не возвращается API. Качество KK нужно проверить на реальных записях.
- Низкая уверенность (ниже `settings.voice.low_confidence_threshold`) или пустая расшифровка → AI просит повторить или
  написать текстом (RU/KK), `meta.stt_low_confidence=true`; третье неразборчивое голосовое подряд → человеку.
- `meta` сообщений теперь отдаётся в `GET /v1/conversations/{id}/messages`; у голосовых —
  `{transcribed, stt, stt_confidence, stt_language, stt_error}`.
- `GET /v1/integrations/stt` → `{provider, configured, model}`; `POST /v1/integrations/stt/test` (владелец) →
  `{ok, provider, latency_ms, error}` по встроенной секундной записи.

### Безопасность — звонки (v1.1.0, часть B)
- `/v1/calls` (список, карточка) и `/v1/reports/voice` учитывают `branch_scope` участника: звонки, связанные с
  клиентом/записью/задачей чужого филиала, скрыты (карточка → 404). Тест добавлен в IDOR-набор.
- Запись разговора, пришедшая без согласия клиента (или при выключенной записи), удаляется в Twilio
  (`VoiceProvider.delete_recording`, REST DELETE), URL не сохраняется; аудит `call.recording_deleted`.
- Задача хранения расшифровок (`ops.voice_retention`) также очищает в `ai_runs` старше срока хранения входы/результаты
  инструментов и текст ответа (id, тайминги, токены, имена инструментов сохраняются).

## [1.0.0] — 2026-11-14 — передача в эксплуатацию (ТЗ §23, фаза 6)

### Добавлено
- **Продакшен-развёртывание** `deploy/`: `docker-compose.prod.yml` (Caddy с автоматическим HTTPS для
  `api.<домен>`/`app.<домен>`, PostgreSQL/Redis без публичных портов во внутренней сети, отдельный шаг миграций,
  healthcheck у каждого сервиса, лимиты ресурсов, ротация логов, non-root, `ENV=production`), `Caddyfile`,
  `.env.production.example`, генераторы секретов `generate-secrets.sh` / `.ps1`.
- **Бэкапы** `deploy/backup/`: ежедневный `pg_dump -Fc`, ротация 7 дневных / 4 недельных, проверка архива,
  sha256, шифрование AES-256 (опц.), выгрузка в S3-совместимое хранилище (опц.), healthcheck «бэкап старше 26 ч»;
  `restore.sh` с проверкой контрольной суммы и сверкой числа строк. Восстановление проверено (docs/OPERATIONS.md).
- **Метрики Prometheus** `GET /metrics`: запросы и латентность по шаблону маршрута и статусу, outbox
  (pending/failed, возраст), открытые и просроченные задачи, уведомления (в т. ч. dead), ошибки AI-ходов,
  эскалационные звонки по статусам, доступность БД, состояние kill switch. Доступ — только внутренняя сеть или
  `METRICS_TOKEN`; Caddy закрывает `/metrics` снаружи.
- **Аварийное отключение AI для всей платформы** `AI_GLOBALLY_DISABLED=true`: оркестратор не вызывает модель,
  клиент получает резервное сообщение, создаётся задача администратору, диалог переходит к человеку; входящие
  звонки сразу переводятся администратору; песочница базы знаний отвечает 503.
- **CLI оператора** `python -m app.cli create-tenant` — организация + владелец + первый филиал, идемпотентно, с аудитом.
- Документация передачи: `docs/HANDOVER.md`, `ARCHITECTURE.md`, `OPERATIONS.md`, `ONBOARDING_BUSINESS.md`,
  `THIRD_PARTY.md`, `ACCEPTANCE_REPORT.md`; руководство пользователя `docs/user-guide/` (RU + KZ-памятка).
- `backend/.dockerignore` (контекст сборки без `.venv`).

### Изменено
- Версия API/пакета `1.0.0`; зависимость `prometheus-client`.
- Старт в production отклоняет `METRICS_TOKEN` короче 24 символов.
